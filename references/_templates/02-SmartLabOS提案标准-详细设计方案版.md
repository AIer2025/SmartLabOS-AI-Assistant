# SmartLabOS 详细设计方案版 · 内容范围标准

> **适用场景：** 中标后/合同前的详细设计、技术评审、工程交底、技术标深化阶段的提案。
> **受众：** 客户技术负责人、检测骨干、工程/IT 评审人员。
> **核心目标：** 证明系统"如何落地、参数达标、流程闭环、工程可施工、软件可集成、实施可管控"，以技术深度与可量化为主。
> **颗粒度：** 细。每条要求具体到参数、图纸、表格、交付物级别。
> **使用方式：** 逐条勾选。★必备 = 缺项即不合格；○按需 = 视项目裁剪但缺项需说明理由。
>
> **本版强制总则：**
> 1. 所有设备/软件指标必须为**具体数值 + 单位 + 精度 + 通讯协议**，禁止"高精度/快速"等定性描述。
> 2. 所有"图 X-X"占位必须替换为实图；所有"GBxxx"等标准号占位必须补全为现行有效标准。
> 3. 每个已配置的功能平台必须满足【平台组成 + 功能说明 + 关键技术指标表】三要素，缺一不可。

## 1. 项目概述 ★必备

### 1.1 客户与业务背景
- [ ] 客户单位性质、级别、职能、资质（复检机构/监督检验/风险监测等）

- [ ] 目标物理化特性（痕量、基质干扰、热敏、易挥发/降解）

### 1.3 现状痛点深度分析 ★必备
- [ ] 前处理各环节人工难点逐项剖析（均质不均、萃取乳化、SPE柱活化/平衡/流速失控、氮吹/浓缩损失、定容精度、离子抑制）
- [ ] 人工操作问题量化（容错率、个体差异、重复性、效率、熟练度依赖）

### 1.4 项目场地概述 ★必备
- [ ] 改造前用途、楼层、房间
- [ ] 场地尺寸（长×宽、面积、层高）+ 原始结构尺寸图

## 4. 功能平台逐一详细设计 ★必备（本版核心）

> **对每一个已配置平台，逐一展开下列三要素**，且必须配示意图：
> - **平台组成**：所含模块清单
> - **平台功能说明**：完成的操作步骤、适配基质/场景、自动化逻辑
> - **关键技术指标表**：逐模块列「设备名称 + 系统指标」，指标须量化并含通讯协议

### 4.1 平台清单（逐平台执行三要素，按项目裁剪）
- [ ] 智能仓库 / 智能线边仓库（含平台示意图 + 指标表）
- [ ] 提取平台（含示意图 + 指标表）
- [ ] 水解平台（均质/加标/调pH）（含示意图 + 指标表）
- [ ] SPE 净化与过滤平台（含示意图 + 指标表）
- [ ] 萃取净化平台（含示意图 + 指标表）
- [ ] 恒温存储平台（恒温衍生 + 低温暂存）（含示意图 + 指标表）
- [ ] 自动化 LC-Q-TOF 检测平台（含示意图 + 指标表）
- [ ] 自动化 LC-MS/MS 检测平台（含示意图 + 指标表）
- [ ] 自动化物流搬运平台
- [ ] 手工实验平台（如保留）

### 4.2 各模块关键技术指标必须覆盖的参数项（核对清单）
- [ ] 搬运/机械臂模块：自由度、有效负载、工作半径、末端速度、重复定位精度、工作温度、安全认证、内置力矩传感（力感应范围/精确度/准确度）、通讯接口
- [ ] 电动夹爪：可调行程、单指夹持力、位置重复精度、掉落检测、通讯协议
- [ ] 加液涡旋模块：液体种类、加液体积范围、重复精度、吸排液精度、涡旋转速、涡旋时长、通讯
- [ ] 加盐/加固体涡旋模块：加固体种类、加盐方式、加盐精度、涡旋参数、通讯
- [ ] 均质模块：均质频率、均质时长、通讯
- [ ] 调 pH 模块：测量范围、调节精度、兼容管型、通讯
- [ ] 振荡/振摇模块：频率、振幅、时长、通讯
- [ ] 离心模块：转速、离心力、兼容管型、温控范围、不平衡报警
- [ ] 移液模块：精度、量程、最大移液速度、过程安全检测（TIP/压力/电容/过程）、Z轴行程与精度
- [ ] SPE 模块：接入试剂种类、流速控制范围与精度、移液体积范围与精度、SPE柱兼容规格、吹干方式、八步操作可编程、通讯
- [ ] 浓缩模块：转速、浓缩效率（注明溶剂/温度）、温度范围与控温精度、通讯
- [ ] 过滤模块：滤膜孔径兼容、过滤压力范围与精度、样品体积、通讯
- [ ] 拆盖/封盖模块：适配容器规格、单次操作时间、成功率、通讯
- [ ] 扫码/识别模块：响应时间、连续识别效率、识别准确率
- [ ] 恒温衍生模块：仓位、兼容管型、温度范围与控温精度、避光、衍生时长可设、流转效率
- [ ] 低温暂存模块：仓位、兼容瓶型、温度范围与控温精度、流转效率
- [ ] 智能仓库：仓位数与分区设计、机械臂定位精度与抓取速度、库存监测更新频率、补料提醒方式与响应延迟、单批次上料时间
- [ ] 检测平台对接（进样暂存）：暂存位数、机械臂定位精度、单批次上料时间、与仪器进样器对接、信息实时传输、标曲自动进样、R²要求

### 4.3 辅助/可选设备 ○按需
- [ ] 纯水制备系统（型号、产水能力、预算）
- [ ] UPS（容量、续航、预算）
- [ ] 增强型 SPE/特殊净化模块（用途、适用分析物、预算）

## 6. 自动化产能效率 ★必备
> 所有效率数据必须对应"具体样品数 × 具体基质 × 全流程耗时"，禁止笼统。
- [ ] 自动化检测效率设计逻辑（多模块并行、全流程联动、节拍匹配）
- [ ] 高通量筛查效率（不同样品数 × 不同基质的全流程耗时实测/测算）
- [ ] 专项/痕量检测效率（如硝基呋喃，含恒温衍生等复杂环节耗时）
- [ ] 多检项复合检测效率（模块分时复用、并行处理整体耗时）
- [ ] 核心通量与周期保障（X天Y样并出报告；年上机针数）
- [ ] 效率提升对比（vs 人工：提升幅度、人力 N→M、错误率 X%→Y%）

## 7. 项目实施与管理方案 ★必备

- [ ] 总建设周期（日历天）
- [ ] 组织架构与职责（乙方项目经理/技术/质控团队 + 甲方对接小组，权责清晰）

- [ ] 阶段三：现场基础施工与复核
- [ ] 阶段四：现场安装与模块拼接
- [ ] 阶段五：系统调试与人员培训
- [ ] 阶段六：项目验收与交付归档
- [ ] 总工期甘特图

### 7.3 项目管理措施
- [ ] 进度管理（三级管控、例会、赶工预案）
- [ ] 质量管理（全流程质控追溯、质控节点、归档）
- [ ] 沟通管理（固定机制、专属群、例会）

### 7.4 保障措施
