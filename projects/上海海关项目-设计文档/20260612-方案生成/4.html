2前处理工艺流程拆解

将标准 8.1 / 8.2 文字流程拆解为可由模组执行的「单元操作」（橙=酶解 §8.1，紫=调 pH / 萃取，绿=SPE 净化 §8.2）。

8.1 酶解与提取 —— 称取试料 2 g 于 50 mL 离心管 → 加 0.2 mol/L 乙酸铵缓冲液 6 mL + β-葡萄糖醛酸酶/芳基硫酸酯酶 40 µL → 涡旋混匀 → 37 ℃ 避光水浴振荡 16 h → 放置至室温备用。
8.2 萃取/净化/浓缩 —— 加内标 100 µL 涡旋 → 8000 r/min 离心 8 min 取上清 → 加高氯酸 5 mL 调 pH 1.0±0.2 → 8000 r/min 离心 → 上清用 NaOH 调 pH 10±0.5 → 加乙酸乙酯 15 mL 振荡 5 min → 5000 r/min 离心 5 min 取上层有机相 → 水相加叔丁基甲醚 10 mL 重复 → 合并有机相 → 50 ℃ 氮吹干 → 2% 甲酸 5 mL 溶解 → MCX SPE 净化（甲醇/2%甲酸活化 → 上样 → 2%甲酸/甲醇淋洗抽干 → 5% 氨化甲醇 3 mL 洗脱）→ 洗脱液 50 ℃ 氮吹干 → 甲醇-0.1%甲酸(10+90) 0.5 mL 复溶 → 0.22 µm 过滤。

7处理耗时测算（逐平台 → 总节拍）

测算口径：每平台处理节拍 = Σ 该平台所载模组（功能码单循环耗时 + 模组上下料时间 60 s）；解决方案总节拍 = Σ 各平台节拍。 数值取自模组卡 process_capability.cycle_time_sec 与 module_up_unload_time.up_unload_time（索引校验值）。

⚠ 通道数 = 2：以下均为「2 样品/循环」的处理节拍，非单样 模组卡的 cycle_time_sec 与上下料 60 s 均按双通道（默认通量 = 2，即一个循环并行处理 2 个样品）标定 （例：上下料 60 s = 15 s × 2 通道 × 2 上下料）。因此下表每一行小计、各工作站合计与解决方案总计，对应的是一个循环 2 个样品的处理时间； 单样均摊 = 对应数值 ÷ 2。

💨 排风 / 通风

  • 涉乙酸乙酯、叔丁基甲醚（易燃）、甲醇、氨化甲醇 + 50 ℃ 氮吹挥发 → 防爆排风
  • 酶解 37 ℃ 避光，注意舱体散热排风
  • 各工站设万向抽气罩，罩口面风速 ≥ 0.5 m/s；排风经活性炭/喷淋处理达标后高空排放
⚠ 高氯酸专用排风（安全关键）
  • WS2 使用 高氯酸（强氧化性、与有机物接触有爆炸风险）调 pH，必须配置高氯酸专用通风系统（带水洗冲淋的耐酸排风管路与风机）。
  • 严禁高氯酸废气与有机溶剂废气共用同一排风管道，须独立成系统、独立排放。
  • 高氯酸操作区与有机萃取区在布局上分隔，避免交叉。

🚰 上水 / 下水 / 废液

  • 上水：一级纯水（GB/T 6682），供配液、SPE 活化/淋洗及清洗用水
  • 下水：平台排废口接独立排废管路，废液不得直排市政下水
  • 高氯酸废液单独耐酸收集并中和；强碱（NaOH）、有机废液（乙酸乙酯/叔丁基甲醚/甲醇）分罐分类，绝不混排；地面设地漏/防渗托盘 + 耐酸地坪

🟦 压缩空气 / 真空

  • 洁净干燥压缩空气 0.4–0.7 MPa（正压加液、SPE、针式过滤模组）
  • 真空泵：SPE 抽干、离心浓缩配套（建议带冷阱）
  • 压缩空气需除水除油，避免污染样品流路
