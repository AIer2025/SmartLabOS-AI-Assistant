1立项背景与缺口判定

依据指令 §5.3：若 97 个 / 11 个已确认模组中无合适模组实现某前处理需求，输出新建模块 URS。

缺口判定
  • 标准 GB/T 21981—2008 §7.2 要求：提取液上样于 ENVI-Carb 柱（500 mg/6 mL） → 减压抽干 → 在其下方串接氨基柱（500 mg/6 mL） → 用二氯甲烷-甲醇溶液 6 mL 串联洗脱并收集 → 取下 ENVI-Carb 柱 → 再用二氯甲烷-甲醇 2 mL 单独洗氨基柱。
  • 已确认清单中唯一自动 SPE 模组 MOD-SPE-004 为单柱、2 路并行结构，固定适配 6cc HLB 柱，不具备双柱垂直串接、上下游柱切换、串联洗脱与“取下上柱后二次洗下柱”能力。
  • 其余 10 个已确认模组无 SPE 净化能力。
  • 结论：构成模组缺口 → 新建 MOD-SPE-D01 串接双柱固相萃取净化模块。

2适用范围与典型场景

  • 动物源食品激素多残留（50 种）净化 —— ENVI-Carb（石墨化炭黑）+ 氨基柱串接，去除色素、脂类、极性干扰。
  • 凡需「上柱富集 → 串接下柱保留/去杂 → 串联洗脱」的双柱 SPE 方法均适用（兽残、农残、真菌毒素等扩展）。
  • 柱规格：6 mL 柱体；填料 100~500 mg，换载具可适配 3cc/6cc。

3功能需求（FRS）

编号功能需求优先级
FR-01双柱垂直串接夹持机构：上柱（ENVI-Carb）出口对准下柱（氨基柱）入口，密封连通且可单独取放上柱。必须
FR-02双柱独立活化：ENVI-Carb 依次二氯甲烷-甲醇 / 甲醇 / 水各 6 mL 活化；氨基柱二氯甲烷-甲醇 6 mL 活化。必须
FR-03上样：提取液（甲醇 25 mL + 水 100 mL ≈ 125~135 mL）以 2~3 mL/min 上样于 ENVI-Carb 柱，注射泵 / 正压流速闭环。必须
FR-04减压抽干上柱；自动完成上柱→下柱串接切换。必须
FR-05串联洗脱：二氯甲烷-甲醇（7+3）6 mL 经 ENVI-Carb→氨基柱串联洗脱并收集于接样瓶。必须
FR-06二次洗脱：取下 ENVI-Carb 柱后，二氯甲烷-甲醇 2 mL 单独洗氨基柱，合并收集。必须
FR-07柱、样品瓶、接收瓶自动上下料（机械臂 / 载台）。必须
FR-08共用针 / 流路自动清洗，防交叉污染。必须
FR-09多路并行（≥2 串接对）以提升通量。期望

8验收准则（DQ / OQ / PQ 要点）

  • DQ：双柱串接夹持、上柱可独立取放、密封无渗漏的结构设计评审通过。
  • OQ：上样流速 2~3 mL/min 闭环 ±5%；洗脱计量 ±2%；抽干真空 ≤ −80 kPa；空白无交叉污染。
  • PQ：以 GB/T 21981—2008 50 种激素基质加标验证，回收率 75.2%~121.8%、RSD 2.4%~20.8% 区间内，达标视为通过。
  • 安全：二氯甲烷流路密封、排风联锁；断电断气维护规程齐备。
