3前处理工艺流程拆解

将标准 §8.1 / §8.2 文字流程拆解为可由模组执行的「单元操作」（蓝=酶解提取 §8.1，绿=净化 §8.2，橙=浓缩定容，青=过滤，紫=存储）。

8.1 酶解提取 —— 称取试料 2 g（±0.05 g）于 50 mL 离心管 → 加 0.2 mol/L 乙酸铵缓冲液（pH 5.2）6 mL + β-葡萄糖醛酸酶/芳基硫酸酯酶 40 µL → 涡旋混匀 → 37 ℃ 避光水浴振荡 16 h → 放置至室温。
8.2 萃取·净化·浓缩 —— 加内标工作液 100 µL 涡旋 → 8000 r/min 离心 8 min 取上清 → 加 0.1 mol/L 高氯酸 5 mL 涡旋、调 pH 1.0±0.2 → 8000 r/min 离心 8 min → 上清 10 mol/L NaOH 调 pH 10±0.5 → 加乙酸乙酯 15 mL 中速振荡 5 min → 5000 r/min 离心 5 min 取有机相 → 下层水相加叔丁基甲醚 10 mL 重复 → 合并有机相 50 ℃ 氮吹干 → 2% 甲酸 5 mL 溶解 → MCX SPE（甲醇 + 2% 甲酸各 3 mL 活化 → 上样 → 2% 甲酸 + 甲醇各 3 mL 淋洗抽干 → 5% 氨化甲醇 3 mL 洗脱）→ 洗脱液 50 ℃ 氮吹干 → 甲醇-0.1% 甲酸（10+90）0.5 mL 溶解 → 0.22 µm 过滤 → 待测冷藏。

  • MOD-LX-001：cycle_time_sec 为「0–300」，取上限 300 s；本方案 3 次离心分别为蛋白沉淀（8000 rpm）与两次 LLE 分相（5000 rpm），均在 ≤8000 rpm 范围内，✓ 满足。
  • MOD-NS-001 ※估：卡片 cycle_time_sec 为空，按同类有机溶剂真空离心吹干工程估算 480 s（见 §5）。
  • MOD-YY-001 ※估：卡片 cycle_time_sec 为 0，按定量环移液/转移工程估算 60 s（见 §5）。
