- 模版含 10 个章节，全部保留：① 项目与标准 ② 工艺流程（含 mermaid flowchart + .proc 文字拆解）③ 平台选型（3 卡片 + 表 + 结论）④ 模组选型（引用真实 MOD ID 表 + 托盘）⑤ 工作站组成（每工站：搭载模组表 + SVG 平台俯视布局 + flowline）⑥ 解决方案串联（mermaid + 表）⑦ 处理耗时测算（逐工站表 + 总节拍表 + 取值说明）⑧ 通量与合规（kpi + 偏差说明）⑨ 公用工程 ⑩ 物料/商务。

## 2. 处理耗时测算规则（任务 4.2，强制）
- **每模组单步耗时 = 功能码单循环耗时 cycle_time_sec + 模组上下料 60s**。所有模组上下料统一 60s。
- **平台节拍 = Σ 该平台所载各模组单步耗时**（与模版口径一致，按"2 样/循环·双通道"标定；单样均摊 = ÷2）。
- **解决方案总节拍 = Σ 各平台节拍**，必须在第⑦节用逐工站表 + 总表明确列出。
- **拆分目标**：每个平台处理时间尽量**相等且尽量接近 600s（10min）**，以此为标准拆分设立平台/工作站。浓缩、超声、酶解等单步极长（如浓缩2640s、酶解16h）是天然瓶颈，无法压到600s时，在 note 中诚实标注瓶颈并给出（增配并行/升级PLT-1400/拆分工站）的均衡建议——做到"尽可能接近"。
- 若国标要求时长与模组卡标称不同（如超声标准要20min=1200s而卡标300s），按**国标时长**取值并加脚注 ※。

## 3. URS 规则（任务 4.3）
- 若 97 模组中**确无**模组能实现某前处理步骤（例：MSPD研磨分散、微波辅助萃取、−18℃冷冻、旋转蒸发、长时酶解恒温等极端工况），则**额外**输出一个 `xxx-模块-URS.html`（命名如 `MSPD研磨-模块-URS.html`），含：用途、URS功能需求、关键参数、SVG/Mermaid 示意。
- 该新建模组的**处理时间采用国标 MD 规定的时长 + 60s 上下料**，并计入所在平台总耗时。
- 能用既有模组近似替代（注明偏差）就优先用既有模组，不要轻易开 URS；仅在确实无任何近似模组时才开。

## 6. 偏差诚实标注
- 离心：标准常要 10000~14000rpm / −2℃；50ml MOD-LX-005 仅 ≤8000rpm、控温1-10℃，达不到时必须在第⑧节"工艺偏差说明"标注，并给建议（选配高速冷冻离心外设 / 方法学验证等效）。高速小体积用 MOD-LX-004(≤14000rpm) 可满足14000rpm。
- 容器体积须匹配（如50ml流程别选2ml模组）。
