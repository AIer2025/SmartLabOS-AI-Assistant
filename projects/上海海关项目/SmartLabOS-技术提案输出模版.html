2前处理工艺流程拆解

将标准 8.1 / 8.2 文字流程拆解为可由模组执行的「单元操作」（蓝=提取 §8.1，绿=净化 §8.2）。

8.1 提取 —— 称取试料 1 g → 加 Mcllvaine Na₂-EDTA 缓冲液 8 mL → 涡旋 1 min → 超声 20 min → −2 ℃ 10000 r/min 离心 5 min → 收集上清；残渣加磷酸盐缓冲液 8 mL 重复提取 1 次 → 合并 2 次提取液。
8.2 净化 —— SPE 柱用甲醇 5 mL + 水 5 mL 活化 → 上样 → 水 5 mL + 20% 甲醇水 5 mL 淋洗 → 抽干 → 洗脱液 10 mL 洗脱 → 45 ℃ 氮吹干 → 复溶液 1.0 mL 涡旋溶解 → 14000 r/min 离心 5 min → 0.22 µm 过滤。

7处理耗时测算（逐平台 → 总节拍）

⚠ 工艺偏差说明（诚实标注，需与客户确认）
  • 8.1 提取离心：标准要求 −2 ℃ / 10000 r/min。模组库 50ml 离心模块（MOD-LX-005 / LX-001）最高 8000 r/min、最低控温 1–2 ℃，无法严格达到 −2 ℃ 与 10000 r/min。建议：① 选配高速冷冻离心外设集成；② 或经方法学验证后以 8000 r/min·≤4 ℃ 等效执行。该点为本方案唯一硬件缺口。
  • 8.2 复溶离心：标准 14000 r/min —— 采用 MOD-LX-004（2ml，1–14000 rpm），✓ 完全满足。
  • SPE 柱型：标准 HLB 200 mg/6 mL —— MOD-SPE-004（6cc 自动上样）柱型一致，✓ 吻合。
合规要点
  • 全部技术参数引用自 references/ 模组/平台/托盘库，无编造数据（已剔除上一版误用的不存在模组）。
  • SPE 活化·平衡·上样·淋洗·吹干·洗脱由 MOD-SPE-004 微升级流速闭环控制，规避柱干、流速不均。
  • 提取涉乙腈、净化涉甲醇/乙酸乙酯/浓氨水/甲酸 + 45 ℃ 氮吹，工站要求通风 + 压缩空气。

  • 独立配电箱 + 漏电/接地保护，设备可靠接地

💨 排风 / 通风

  • 提取涉乙腈，净化涉甲醇、乙酸乙酯、浓氨水、甲酸 + 45 ℃ 氮吹挥发
  • 各工站上方设万向抽气罩 / 防爆排风，罩口面风速 ≥ 0.5 m/s
  • 排风经活性炭 / 喷淋处理达标后高空排放

🚰 上水 / 下水 / 废液

  • 上水：一级纯水（GB/T 6682），供 SPE 活化/淋洗及清洗用水
  • 下水：平台排废口接独立排废管路，废液不得直排市政下水
  • 有机废液与氨性废液分类收集至危废中转罐，集中处置；地面设地漏/防渗托盘

🟦 压缩空气 / 真空

  • 洁净干燥压缩空气 0.4–0.7 MPa（正压加液、SPE、针式过滤模组）
  • 真空泵：2ml 高速离心模组 MOD-LX-004 配套
  • 压缩空气需除水除油，避免污染样品流路
