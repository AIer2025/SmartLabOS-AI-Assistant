## 1. 任务背景

上海海关需实现 8 个检验标准的实验室样品前处理流程自动化。要求：从 SmartLabOS 知识库（97 个模组 / 3 类平台 / 托盘库）选型，将每个国标的「提取 + 净化」流程拆解为模组 → 平台 → 工作站 → 解决方案串联，并以统一 HTML 模版输出，含逐平台耗时测算。

**知识库结构（references/）**
| 层级 | 目录 | 含义 |
|---|---|---|
| 模组 | `01-modules`（97 个） | 最小功能单元（YAML-MD），含功能码、单循环耗时、模组位、上下料时间 |
| 平台 | `02-platforms`（3 种） | PLT-800 / PLT-1200 / PLT-1400，承载模组与托盘 |
| 工作站 | `03-workstation` | 选定平台 + 搭载模组，完成一段前处理功能 |
| 解决方案 | `04-solutions` | 多工作站按流程串联，完成完整样品制备 |
| 项目 | `05-Project` | 客户项目（含多个解决方案） |
| 托盘 | `06-pallet` | 一平台最多 6 模组位 + 8 托盘位 |

## 2. 生成方法（工作流）

1. **理解阶段**：读取模组/平台/工作站/解决方案 schema + 输出模版 HTML，确认数据模型与耗时口径。
2. **构建共享数据**：用脚本抽取全部 97 个模组的关键字段（ID、名称、类别、体积、模组位 slots、功能码、单循环耗时、上下料 60s），固化为 `_build/SHARED-BRIEF.md`（含平台规格、占位规则、耗时规则、URS 规则、输出格式、自检清单）。这是所有方案的唯一选型依据。
3. **并行生成**：1.html 直接采用已完成的模版范例（即标准 1 的完整方案）；2~8.html 由并行子代理生成，每个子代理读取「共享简报 + 输出模版 + 对应国标 MD」后产出 HTML（无合适模组时按规则产出 URS）。
4. **独立校验**：对全部 8 文件，独立提取所有 MOD-/PLT- 编号比对目录（防编造）、核对章节齐全度/mermaid/SVG/价格合规、抽查耗时算式。
5. **冲突修正**：发现 8.html 的国标原文与任务粘贴文字不一致，经用户确认后按国标原文重建。

**关键口径（任务 4.2）**
- 每模组单步耗时 = 功能码单循环耗时（`cycle_time_sec`）+ 模组上下料 60s（全库统一 60s）。
- 平台节拍 = Σ 该平台所载模组单步耗时（按"2 样/循环·双通道"标定，单样均摊 = ÷2）。
- 解决方案总节拍 = Σ 各平台节拍。
- 拆分目标：各平台耗时尽量相等且接近 600s（10 min）；浓缩/超声/酶解等超长单步为天然瓶颈，无法压到 600s 时诚实标注并给均衡建议。
- 国标时长与模组卡标称冲突时，取国标时长并加脚注 ※。

## 4. 质量校验结果

- ✅ **零编造**：全部 8 文件引用的 MOD-/PLT- 编号逐一比对 97 模组目录 + 3 平台，均真实存在。
- ✅ **结构齐全**：每文件 10 章节（项目与标准 / 工艺流程 / 平台选型 / 模组选型 / 工作站组成 / 解决方案串联 / 处理耗时测算 / 通量与合规 / 公用工程 / 物料商务），含 mermaid 流程图与各工站 SVG 平台俯视布局。
- ✅ **耗时测算**：每文件含逐工站表 + 总节拍表，算式 = Σ(cycle + 60)，并讨论与 600s 的接近度。
- ✅ **价格合规**：全部以「涉及价格、报价信息请联系销售团队获取报价」处理，无数字报价。
- ✅ **模组位约束**：每工站模组位合计 ≤6（离心模组占 3 位、JY-012/部分超声占 0 位均已计入）。

## 5. 需销售 / 工艺后续确认的诚实偏差

1. **离心转速缺口**：GB 31658.22/23/28、GB/T 21981 等要求 10000~14000 rpm（部分 −2℃）。50ml 离心模组 MOD-LX-005 仅 ≤8000 rpm、控温 1~10℃，无法严格达标。建议：① 选配高速冷冻离心外设集成；② 或经方法学验证以 8000 rpm·≤4℃ 等效执行。高速小体积 14000 rpm 由 MOD-LX-004 满足（1 号方案）。
2. **超长反应瓶颈**：4 号酶解 16h、6 号酶解 2h+冷冻、8 号酶解 12h，单步远超 600s/平台目标。已标注为天然瓶颈，建议多套酶解工站并行（8~16 套）+ 夜间无人运行掩盖通量。
3. **MSPD 研磨近似**：2 号 MSPD 玻璃研钵分散研磨以均质模块 MOD-JZ-002 近似，已注明偏差。
4. **恒温振摇腔规格**：酶解采用 MOD-FY-002（标称 5ml 腔）按国标时长扩时运行，建议定制 50ml 恒温振摇腔。
5. **8.html 依据修正**：任务粘贴的 3.8 流程文字与 3.7 雷同（疑似复制误植），与实际国标文件 `11-GBT21981-2008.md` 不符。经确认按**国标原文**（酶解+ENVI-Carb 双柱）重建，符合「严格遵循国标」原则。
