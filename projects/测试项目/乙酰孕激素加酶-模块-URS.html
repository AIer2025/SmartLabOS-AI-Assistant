50 ml 离心管微量加液涡旋模块（加酶）
URS-JY-μ01 · User Requirement Specification

用于 GB 31658.28—2025 乙酰孕激素类残留检测中 β-葡萄糖醛苷酶/芳基硫酸酯酶 100 µL 的 µL 级精密加注与涡旋混匀。现有确认模组（WX-006 ≥1 mL、YY-002 0.5–1 mL、YY-003 1–10 mL）量程不足，本 URS 定义补足该缺口的新建模组需求。

1背景与目的

本 URS 由 SmartLabOS 售前技术方案（GB 31658.28—2025 乙酰孕激素类前处理方案，成都食检院）派生，用于定义一款补足「µL 级微量加注」缺口的新建模组需求。

项目内容
需求来源GB 31658.28—2025 §8.1「混匀后加 β-葡萄糖醛苷酶/芳基硫酸酯酶（10000 U/mL）100 µL，55 ℃ 避光水浴振荡 2 h」
现状缺口已确认模组 MOD-WX-006（正压加液 1–50 mL）、MOD-YY-002（0.5–1 mL）、MOD-YY-003（1–10 mL）最小量程均 ≥ 0.5 mL，无法在 100 µL 保证 ±1% 精度
目的提供 10–1000 µL 精密微量加注 + 涡旋混匀一体化模组，实现加酶自动化、高重复性、防交叉污染
价值消除人工微量加酶个体差异，保障酶解一致性与基质匹配外标法定量准确度（回收率 60%~120%、批内 RSD ≤ 15%、批间 RSD ≤ 20%）
与现有模组的关系本模组为 MOD-WX-006「50ml 离心管正压加液涡旋模块」的微量量程衍生型，沿用其离心管拆/合盖 + 涡旋机构与平台接口，仅将加液单元替换为高精度微量注射泵/微量分液通道，最大化复用成熟结构、缩短开发周期。

2适用范围与对象

要素要求
操作对象容器50 ml 离心管（Φ34.6 mm，与 WX-006/YJ-004/LX-001 同容器体系，兼容平台 EPG40/ERG32 夹爪间距 16）
加注试剂β-葡萄糖醛苷酶/芳基硫酸酯酶（生物酶，10000 U/mL，加注 100 µL，粘度低-中、易起泡）
加注体积范围10–1000 µL（覆盖 100 µL 及余量，兼顾多基质/未来微量试剂扩展）
混匀方式加注后离心管拆盖/合盖 + 涡旋混匀（沿用 WX-006 涡旋机构，1–3000 rpm 可设）
兼容平台PLT-1200（主）/ PLT-800 / PLT-1400；占 1 个标准模块位；双工位（2 样/循环）

3功能需求（★必备 / ○可选）

编号功能需求优先级
F-01自动拆盖：夹紧 50 ml 离心管，旋转拆下管盖并保持夹持★必备
F-02微量加注：从酶试剂瓶精密吸取 10–1000 µL 并加注入离心管（本项目工况 100 µL），预留 ≥2 试剂通道以适配多基质/未来扩展★必备
F-03枪头/针防污：一次性枪头或加注针自动更换/清洗，杜绝样品间携带污染★必备
F-04涡旋混匀：加注后合盖并涡旋，转速 1–3000 rpm、时长可设（对应标准「混匀后」）★必备
F-05自动合盖 + 上下料：与 XYZ 机械臂对接，双工位并行★必备
F-06液位/吸空检测：吸液异常（吸空、堵塞、气泡）报警并暂停○应有
F-07酶活保护：酶试剂通道支持低温位/避光，加注针低死体积、快速加注，减少酶暴露与活性损失○应有
F-08加注量在线记录：每管加注体积上传中控，支持追溯○可选

6接口与公用工程需求

类别需求
机械接口标准模块位（180×450×600 mm）；与 PLT-1200 XYZ 机械臂对接，兼容 ERG32-150T/EPG40-50 夹爪（间距 16，Φ34.6 mm 50ml 离心管）
电气DC 24 V 供电；功率 ≤ 0.4 kVA（拟）
气源洁净干燥压缩空气 0.4–0.6 MPa（拆合盖/涡旋压板/正压）
试剂供给酶试剂瓶（建议低温位、避光）+ 预留通道，独立管路/枪头，低死体积
耗材一次性微量枪头或可清洗加注针 + 洗针池（纯水/清洗剂）
通讯MODBUS TCP，接入 SmartLabOS 中控调度与追溯
上下水若采用洗针方案：需纯水上水 + 排废下水

7安全与合规要求

  • 运行中严禁伸手进入拆合盖/涡旋运动区；每工位配急停，异常先断电断气再排查。
  • 酶试剂建议低温存放通道、避光，避免活性下降；加注前确认无吸空、无气泡。
  • 加注针/枪头一用一换或彻底洗针，杜绝样品间携带污染。
  • 设备可靠接地；❌ 潮湿环境使用；维护需断电断气。
  • 加注量、报警、耗材更换记录纳入中控日志，支持正/反向追溯（GLP/CNAS 可追溯要求）。

8验收标准与耗时归集

验收项判定标准
加注准确度称量法：100 µL ≥ 10 次，准确度 ≤ ±1%（≥100 µL）/ ±2%（<100 µL）
重复精度RSD ≤ 0.5%（≥100 µL）/ ≤ 1%（<100 µL）
交叉污染空白携带 < 定量限，通道间互不干扰
节拍双工位单循环 ≤ 200 s（不含上下料）
通讯联调MODBUS TCP 与中控指令/状态/追溯数据交互正常
耗时归集（计入本方案平台总耗时）本模组处理时间 = URS 拟定 200 s（功能循环）+ 60 s（自动上下料）= 260 s / 2 样循环；计入 WS-01（加酶）工站节拍，已在解决方案 1.html §7 耗时测算中体现。
