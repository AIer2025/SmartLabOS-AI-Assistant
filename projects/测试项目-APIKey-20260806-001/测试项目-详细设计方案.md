## 1. 项目概述

### 1.1 客户与业务背景

成都市食品检验研究院隶属成都市市场监督管理局，为**正处级公益二类事业单位**，承担食品、食用农产品等的**监督检验、风险监测与技术研究**职能，是**国家食品复检机构**，牵头食用农产品抽检监测，并持续开展多兽药残留检测技术攻关。

本项目针对该院**兽药残留专项检测**的前处理自动化改造，核心目标是以「多品类兽残高通量大筛查」为基础，深度整合自动化前处理与上机检测全流程，同步覆盖**硝基呋喃、氯霉素、磺胺类、沙星类（喹诺酮类）四大重点兽残**的全自动化前处理，实现"提质增效、结果精准可控"。

| 客户属性 | 说明 |
| --- | --- |
| 单位性质 | 公益二类事业单位（正处级） |
| 行政级别 / 主管 | 市级 / 成都市市场监督管理局 |
| 核心资质 | 国家食品复检机构、食用农产品抽检监测牵头单位 |
| 职能范围 | 监督检验、风险监测、技术研究、多兽残检测攻关 |
| 本期建设范围 | 兽残检测全流程前处理自动化（采样、制样、分样、前处理、检测、出报告） |

### 1.2 检测对象与目标物

| 目标物类别 | 代表化合物 | 基质范围 | 理化 / 前处理难点 |
| --- | --- | --- | --- |
| 硝基呋喃类代谢物 | AOZ、AMOZ、SEM、AHD 等 | 肌肉、蛋奶、鱼肉（水产） | 需酸性水解释放结合态 + 衍生化（2-硝基苯甲醛）+ 长时恒温避光反应，热敏、易降解 |
| 氯霉素 | 氯霉素（CAP） | 动物肌肉、水产 | 痕量（µg/kg 级），乙酸乙酯萃取易乳化 |
| 磺胺类 | 磺胺甲噁唑等 21 种 | 畜禽肉、蛋奶 | 极性范围宽，需缓冲液提取 + HLB SPE 净化 |
| 沙星类（喹诺酮） | 恩诺沙星等 | 畜禽肉、水产 | 两性化合物，pH 敏感，需酸性提取 + SPE 净化 |

> 目标物共性：**均为痕量残留、基质干扰极强**，前处理是核心控险环节，直接决定回收率、精准度与结果有效性。基质覆盖畜禽肉（高脂高蛋白）、水产、蛋奶等多类型，前处理需兼顾**高通量筛查**与**靶向定量**双重需求。

### 1.3 现状痛点深度分析（人工前处理）

| 环节 | 人工操作难点 | 量化 / 机理影响 |
| --- | --- | --- |
| 称样 / 均质 | 高脂高蛋白基质易分层、均质不均 | 痕量兽残取样偏差大、重复性差，直接放大结果 RSD |
| 萃取 | 乙腈 / 乙酸乙酯萃取极易乳化、分层困难 | 目标物随乳化层损失，回收率波动大 |
| 加盐盐析 | 无水硫酸钠 / 氯化钠称量与投加依赖人工 | 加盐量偏差影响分层与回收 |
| SPE 净化 | 活化、平衡、上样、淋洗、洗脱**流速人工把控难** | 易柱干、堵塞、填料吸附，回收率批间波动大 |
| 浓缩 / 氮吹 | 控温控速难 | 热敏目标物分解、易挥发目标物损失，定容精度不足 |
| 衍生 / 调 pH（硝基呋喃） | 衍生温度/时间、pH 终点靠人工经验 | 衍生不充分、pH 偏离导致定量偏差 |
| 全流程 | 步骤繁琐、**全程手工容错率极低**，高度依赖人员熟练度 | 个体差异大、重复性差、效率低，基质杂质引发严重**离子抑制** |

### 2.4 差异化检项的系统适配与调度说明

- **高通量兽残（磺胺/沙星/氯霉素/127 种筛查）**：走"提取→SPE 净化→浓缩复溶→高速离心→过滤"主链，无需水解衍生，节拍短、批量大；
- **硝基呋喃专项**：额外插入"均质→加酸水解→加内标/衍生剂→恒温反应→调 pH"前段，反应时长（金属浴恒温）为瓶颈，采用**大批量装载 + 恒温位缓存**并行消化长反应时间；
- 中央控制系统按**检测标准库 + 实验流程库**自动为每个样品条码匹配工艺模板，动态调度共享模块（如离心、SPE、浓缩），实现多标准并行、错峰复用。

## 3. 总体设计

### 3.1 设计依据与原则

**设计原则**

1. **模块化**：全部功能由标准模块（180×450×600 mm 标准模块位）在 PLT-1200 标准平台上组合，支持后期增删、扩容；
2. **智能物流联动**：样品以标准托盘为载体，平台间由搬运/转运实现流转，工站内由 XYZ 机械臂 + 夹爪完成取放；
3. **数字化管理**：SmartLabOS 智慧实验室软件统一调度、采集、追溯，对接客户 LIMS；
4. **可扩展**：单平台预留模块位/托盘位，产线可按检项增长横向复制平台。

**业务闭环范围界定**

```
采样 → 制样 → 分样 →（人工称样上料）→ 均质 → 加标/水解/衍生 → 调pH → 恒温反应
   → 提取（加液涡旋·加盐·振荡混匀·离心·上清转移）→ SPE 净化 → 浓缩复溶
   → 高速离心 → 过滤 → 进样小瓶 →（对接）LC-MS/MS / LC-Q-TOF → 数据/报告
```

> 自动化边界：本方案自动化范围自「均质/加液」起，至「过滤进样小瓶」止。**称样（0.01 g 感量天平）**因 SmartLabOS 模块库无称量模块，按行业惯例保留人工称样后上料（见 4.3 与偏差说明）。采样/制样/分样与报告出具由客户既有流程 + SmartLabOS 样品管理软件闭环。

### 3.2 整体布局设计

本产线由 **6 个功能平台 + 中央控制/物流** 构成，全部功能平台均采用 **PLT-1200 标准平台**（存储平台采用 PLT-800），沿"前处理工艺顺序"直线/L 形排布：

| 区位 | 平台 | 平台型号 | 主要功能 | 占地 |
| --- | --- | --- | --- | --- |
| P1 | 智能低温存储平台 | PLT-800 | 样品/进样瓶 0~10 ℃ 暂存与自动存取 | 0.68 ㎡ |
| P2 | 水解·均质·加标·调 pH 平台 | PLT-1200 | 均质、加酸水解、加内标/衍生、恒温反应、调 pH | 1.02 ㎡ |
| P3 | 提取平台 | PLT-1200 | 加液涡旋、加盐盐析、离心分层、上清全量转移 | 1.02 ㎡ |
| P4 | SPE 净化平台 | PLT-1200 | HLB 固相萃取（活化/上样/淋洗/洗脱），4 柱并行 | 1.02 ㎡ |
| P5 | 浓缩·复溶·离心·过滤平台 | PLT-1200 | 离心浓缩至干、复溶、14000 rpm 离心、0.22 µm 过滤 | 1.02 ㎡ |
| C | 中央控制 + 物流 | — | 工控机/调度、机械臂转运、废液收集 | 随平台 |

**布局合理性论证**：① 按工艺流向单向排布，避免样品回流与交叉污染；② 涉挥发有机溶剂（乙腈、乙酸乙酯、甲醇）与恒温挥发的 P2/P3/P5 集中于排风罩下；③ SPE 与浓缩为通量瓶颈，居中布置便于机械臂两侧取放缓存；④ 低温存储 P1 靠近产线出入口，兼作进样前暂存与前处理成品缓存。

> **标准化预装与现场拼接**：各平台在厂内完成模块装配、走线、单机 FAT 测试后整体运输，现场仅需拼接定位、接入水电气与网络，**大幅缩短现场建设周期**（现场安装约 4 周，见第 7 章）。

> **布局图（交付物）**：智能化实验室规划布局图 / 平台俯视排布 CAD 图，将在阶段一现场复测（开间×进深、梁柱、门窗、管井位置）后出具正式版并随详细设计冻结提交；本节以区位表 + 文字论证替代占位图，避免使用未经现场核实的图纸。

## 5. 软件系统详细设计

> 本项目软件为 SmartLabOS **智慧实验室软件**，统一承担调度控制、样品/物料/设备全生命周期管理、数据采集与 LIMS 对接、可视化与预警。下述功能为 SmartLabOS 标准能力；涉及具体阈值/模板/角色的配置项在实施阶段随 URS 确认（标注"配置项"），不预设臆造数值。

### 5.1 中央控制系统

**① 技术架构**

- 分层架构：**现场设备层（PLC/模块）→ 数据采集与控制层（工控机）→ 业务应用层（调度/管理）→ 展示层（B/S 前端 + 大屏）**；
- 部署方式：本地服务器部署，B/S 架构浏览器访问；现场每平台配工控机（HMI）执行单机流程；
- 通讯：设备侧 MODBUS TCP/工业以太网（SPE-004 已明确 MODBUS TCP），上层 RESTful API + HTTPS。

### 6.3 效率设计逻辑与提升对比

- **设计逻辑**：多模块并行（离心 4 孔位、SPE 4 柱、高速离心 6 孔位）、全流程联动、节拍匹配调度；长反应（恒温衍生、浓缩）以缓存位并行消化；
- **核心保障**：满足客户"高通量 96 样/24 h、硝基呋喃 48 样/36 h、8 线并行"目标；
- **对人工的提升**：全程替代人工均质、萃取、加盐、SPE、氮吹等繁琐操作，从根本上消除均质不均、乳化损失、SPE 流速失控、氮吹挥发损失、pH/衍生个体差异等痛点，显著提升回收率与重复性、降低离子抑制。

> **待补确认（效率对比量化）**：人力 N→M、错误率 X%→Y%、回收率/RSD 提升幅度需以客户**现有人工基线数据**与设备到场后的**方法学验证/OQ-PQ 实测**为准，本方案不预填未经验证的对比数值。

## 附. 待客户/厂内确认信息汇总（重要）

1. **场地**：房间用途/楼层/房间号、开间×进深实测、梁柱与隔断打通范围、原始结构尺寸图。
