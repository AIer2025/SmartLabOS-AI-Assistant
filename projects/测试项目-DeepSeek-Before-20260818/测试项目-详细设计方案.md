# 1. 项目概述

## 1.1 客户与业务背景

成都市食品检验研究院隶属成都市市场监督管理局，为**正处级公益二类事业单位**，是**国家食品复检机构**，承担食品、食用农产品等的监督检验、风险监测与检验技术研究，并牵头食用农产品抽检监测、开展多兽药残留检测技术攻关。其职能定位要求检测结果具备**法律效力与复检权威性**，对前处理环节的准确度、重复性、可追溯性提出了高于一般检测机构的要求。

本项目面向该院**兽药残留专项检测**业务，目标是构建一条覆盖"采样—制样—分样—前处理—检测—出具报告"的全流程自动化产线，重点解决**硝基呋喃、氯霉素、磺胺类、沙星类**四大类兽残检测中前处理环节的人工痛点，实现高通量筛查与靶向定量并重、结果精准可控。

> **典型标准适配说明：** 本方案的自动化前处理产线以 SmartLabOS 模块化平台组装，工艺流程以国标 **GB 31658.28—2025《食品安全国家标准 动物性食品及尿液中乙酰孕激素类药物残留量的测定 液相色谱-串联质谱法》**为详细工艺样板进行深化设计（含酶水解、乙腈提取、盐析分层、冷冻离心、除脂 SPE 净化、浓缩、复溶、过滤全链条）。该样板与硝基呋喃/氯霉素/磺胺/沙星四类兽残"提取—净化—浓缩—定容—进样"的前处理范式高度一致，模块可分时复用、参数可配置切换，故以此为主线展开详细设计；四类专项检项的差异化适配见第 2 章。

## 1.2 检测对象与目标物

| 项目 | 内容 |
|---|---|
| 检测大类 | 硝基呋喃类代谢物、氯霉素、磺胺类、（喹诺酮）沙星类兽药残留 |
| 工艺样板目标物 | GB 31658.28—2025：醋酸氟孕酮、醋酸甲地孕酮、醋酸美仑孕酮、醋酸氯地孕酮、醋酸甲羟孕酮（MPA，需单独配制）、醋酸羟孕酮共 **6 种乙酰孕激素类**（基质匹配**外标法**定量） |
| 适用基质（样板） | 猪 / 牛 / 羊 / 鸡的**肌肉、脂肪、肝脏、肾脏**组织，以及**牛奶、羊奶、乳粉（牛/羊）、鸡蛋、猪尿、牛尿** |
| 灵敏度 / 准确度（样板） | 检出限 0.2 µg/kg（MPA 0.4 µg/kg）、定量限 0.5 µg/kg（MPA 1.0 µg/kg）；回收率 60%～120%；批内 RSD ≤ 15%、批间 RSD ≤ 20% |

**目标物理化特性与前处理难点关联：**

- **痕量残留**（µg/kg 级）：取样代表性与全流程损失控制直接决定检出能力，任何环节的微小偏差都会被放大。
- **基质干扰极强**：高脂高蛋白基质易分层、易乳化、杂质多，引发严重离子抑制。
- **热敏 / 易挥发 / 易降解**：浓缩控温控速要求高，过热或过吹造成目标物损失。
- **需酶水解与除脂净化**（样板）：µL 级加酶的精度直接关系酶解效率与定量准确度。

## 1.3 现状痛点深度分析

客户提出的人工前处理核心难点，逐环节剖析其影响机理，并映射到本方案的自动化对策（对策模块均取自本项目已确认的选型范围，参数见第 4 章）：

| 人工痛点环节 | 问题量化 / 机理 | 对回收率·精准度·有效性的影响 | 本方案对策模块 |
|---|---|---|---|
| 全程手工、对熟练度依赖高 | 容错率极低，个体差异大，步骤繁琐 | 重复性差、批间波动大、结果可比性不足 | 全流程程控替代人工，参数固化于中控流程库 |
| 样品均质易不均、高脂高蛋白分层 | 痕量取样偏差大、代表性差 | 回收率与重复性同步劣化 | `MOD-JZ-002`（1000–30000 r/min 高剪切+空化，刀头自动清洗） |
| 乙腈提取加盐后极易乳化、分层困难、目标物损失 | 乳化层夹带、提取液回收不全 | 回收率偏低且波动 | `MOD-YJ-004`（定量加盐涡旋盐析）+ `MOD-LX-001`（离心破乳分相）+ `MOD-YY-003`（精准取上层） |
| SPE 柱活化/上样/流速人工难控 | 柱干、堵塞、填料吸附，流速不均 | 目标物穿透/吸附偏差，回收率波动大 | `MOD-SPE-004`（注射泵流速闭环 0.1–15 mL/min，±1%，收集流出液全程程控） |
| 氮吹浓缩控温控速难、定容精度不足 | 过热分解、过吹挥发、体积漂移 | 热敏物损失、定量偏差 | `MOD-NS-005`（25–55 ℃控温+真空 −95 kPa+离心扩面，40 ℃覆盖标准）+ `MOD-YY-002`（复溶 ±1%） |
| 基质杂质难除引发离子抑制 | 信号抑制、定量失准 | 结果有效性下降 | 增强型除脂 SPE 去脂 + 二次复溶除杂，降低基质效应 |

## 2.4 差异化检项的系统适配与调度说明

- **工序复用：** 四类兽残前处理均落入"提取/酶解—净化—浓缩—定容—过滤"范式，可共用 WS-01/03/05/06/07；差异集中在净化柱型（HLB / 除脂柱）、是否需要水解衍生、是否需要调 pH。
- **参数化切换：** 加液体积、涡旋/振荡转速时长、离心转速时长、浓缩温度/时长、SPE 流速与体积，均由中控**检测流程库**按检项模板下发，切换检项无需改硬件。
- **柱型/载具更换：** `MOD-SPE-004` 通过更换载具适配 3cc/6cc SPE 柱，填料在除脂柱（EMR-Lipid 或相当）/ HLB 间按检项更换。
- **衍生工序（硝基呋喃）：** 复用 `MOD-PY-002` 金属浴（25–70 ℃）作恒温衍生工位，避光需选配遮光罩。
- **调度：** 中控按检项优先级与瓶颈工站（浓缩）动态排产，同批次同检项聚批以减少柱型/试剂切换。

# 3. 总体设计

## 3.1 设计依据与原则

**设计原则：**

1. **模块化组装**——全部功能由标准模块位（180×450×600 mm）模块 + 标准托盘位（130×250×150 mm）组成，一个平台最多 **6 模块 + 8 托盘**（PLT-1200）；离心类大体积模块（`MOD-LX-001`、`MOD-LX-004`）占 3 个模块位。
2. **智能物流联动**——XYZ 机械臂 + 平行/旋转夹爪 + 托盘缓存实现工站内与工站间自动流转，自动上下料，无人值守。
3. **数字化管理**——SmartLabOS 中控统一调度、样品全生命周期追溯、数据抓取与 LIMS 对接、数字孪生可视化。
4. **可扩展**——瓶颈工站（浓缩）可通过复制平台/增配并行模块线性扩容；平台预留 UPS 接口与备用模块位。

**业务闭环范围界定：**

```
采样 → 制样(均质) → 分样/称样 → 前处理[酶水解→乙腈提取(盐析)→冷冻离心→除脂SPE→浓缩→复溶→过滤]
     → 上机检测(LC-MS/MS) → 数据处理 → 出具报告
```

- **自动化覆盖范围：** 自"均质·加缓冲液"起，至"0.2 µm 过滤进样"止。
- **人工/线边保留环节：** 称样（5 g，感量 0.01 g，SmartLabOS 模块库无称量模块，按行业惯例人工/线边天平称样后上样）；−18 ℃ 冷冻 30 min 由外部深冷冰箱承载（见第 8 章/附 A 偏差）。

       │

                                              │

**布局合理性论证：**

- **直线流水**：主线按工序顺序直线排列，缩短机械臂/转运行程，−18 ℃ 冷冻节点嵌入 WS-03 与 WS-04 之间就近布置。
- **空间利用率**：PLT-1200 单机占地 1.02 ㎡，7 座净占地约 7.14 ㎡。

## 3.3 配套基础设施改造设计

> 以下为改造设计要点与接口要求；详细的排风/气路/强弱电/给排水改造图纸待现场勘测后出具（列入第 8 章交付物）。

- **管道排风系统改造：** 全线涉**乙腈、甲醇**（易燃）与**乙酸铵、甲酸**。要求：各工站上方设万向抽气罩 + 防爆排风，罩口面风速 ≥ 0.5 m/s；`MOD-LX-001`、`MOD-NS-005` 卡片标注 `requires_ventilation=true`，浓缩 40 ℃ 挥发需局部排风；排风经活性炭处理达标后高空排放。
- **气路分布系统改造：** 提供洁净干燥**压缩空气 0.4–0.7 MPa（1–4 bar，浓缩模块 1–6 bar）**至每座平台（几乎所有模块正压加液/夹紧/吹干均需，卡片 `requires_compressed_air=true`）；配**真空泵**支线：`MOD-LX-001`（−80 kPa）、`MOD-LX-004`（−75 kPa）、`MOD-NS-005`（−95 kPa）。压缩空气须除水除油。
- **强弱电与网络改造：** 主电 **AC 220 V 单相**（金属浴/离心/浓缩）+ 控制电 **DC 24 V**；`MOD-NS-005`、`MOD-YJ-004` 需 **DC 48 V**；独立配电箱 + 漏电/接地保护，设备可靠接地；标配 **3 kVA 在线式 UPS** 接口；工业以太网布线接入中控（设备层通讯 **MODBUS TCP**）。
- **给排水/纯水管路改造：** 上水为一级纯水（GB/T 6682），供 `MOD-JZ-002` 刀头清洗、`MOD-SPE-004` 洗针用水；`MOD-JZ-002`/`MOD-SPE-004`/`MOD-NS-005`/`MOD-GL-002` 卡片标注 `requires_drain=true`，须接**独立排废管路**；有机废液（乙腈/甲醇）**分类收集**至危废中转罐，**严禁直排市政**；地面设地漏/防渗托盘。另预留**外部深冷冰箱**（−18 ℃）位置与供电。

# 5. 软件系统详细设计

> **数据来源说明：** SmartLabOS 中央控制系统的**设备层通讯协议 MODBUS TCP** 由模块卡片确认（`MOD-SPE-004` "仅支持 MODBUS TCP"、`URS-JY-μ01` URS）。软件的功能架构与上层集成指标属产品级能力，知识库未提供逐项数值，本章据 SmartLabOS 智慧实验室软件产品能力描述，凡属**目标值/待现场确认**者均已标注，不作编造。

## 5.1 中央控制系统

**① 技术架构（B/S + 分层 + 分布式设备调度）**

采用四层架构，B/S 架构部署，前后端分离：

```
┌─────────────── 展示层（B/S 浏览器 + 数字孪生大屏） ───────────────┐
├─ 应用层：样品管理·仓库管理·实验流程管理·实验调度·设备管理·报表报告 ─┤
├─ 服务层：调度引擎·数据采集与校验·LIMS 对接·权限·日志·报警 ──────────┤
└─ 设备层：各模块 PLC（MODBUS TCP）·XYZ 机械臂·平台传感器 ─────────────┘
```

- 部署方式：中控服务器（本地机房）+ 客户端浏览器；支持与院内 LIMS/信息化系统对接。
- 设备层：每模块 PLC 经 **MODBUS TCP** 接入调度引擎，支持集中调度 + 单机分散控制两种模式。

**② 功能模块清单**

基础数据管理、样品管理、仓库管理（含耗材/试剂/托盘库存）、实验流程管理、实验调度、设备管理与自动化执行、数字化大屏。

**③ 自动化功能（逐项）**

- **实验室调度控制：** 按检项模板与瓶颈工站（浓缩）动态排产，工站间机械臂流转与 −18 ℃ 冷冻外部节点编排。
- **单机设备执行：** 下发 SPE 上样流速/体积、离心转速/时长、浓缩温度/时长、加液体积等参数至模块 PLC。
- **仓库管理与物料调度：** 托盘/耗材/试剂库存监测、补料提醒。
- **检测标准库与实验流程库：** 内置 GB 31658.28—2025 等流程模板，四检项参数化切换（见 2.4）。
- **样品全生命周期管理：** 采样前/中/后 + 申请-审批-确认-记录闭环，条码绑定（ERG32 旋转夹爪扫码）。
- **设备台账与运维：** 保养提醒（模块维护周期 6 个月/平台年度大保养 + 季度点检）、故障报警、正/反向追溯。

**④ 数据管理功能（逐项）**

- 实验数据抓取与传输、**LIMS 双向对接**（RESTful API/HTTPS，接口清单待现场确认）、通风/有害气体监测联动、多通道实时采集与校验、数据清洗、数据审查与质控校验、实时存储与多维查询。

**⑤ 其他功能**

- 智能监测分析与预警；报表与统计（设备使用/检测次数/试剂用量/异常判定/原始记录与报告导出）；报告定制与一键生成（模板定制 + 多级审核）；数据导出（Word/Excel/PDF）；角色与权限分级管理（可自定义角色）；报警管理（实时/历史、规则配置、多通道通知）；数据安全（冗余容错、传输存储加密、权限隔离）。

## 5.2 数字孪生 / 可视化系统（○按需 → 本项目配置）

客户明确需要"智慧实验室软件"，本项目**配置**数字孪生可视化系统（非裁剪）：

- **系统组成：** 中央控制可视化、试剂耗材管理可视化、物流与设备运行监控。
- **五大功能：** ① 实时数据展示与监控（各工站状态、节拍、温度/转速/流速等）；② 实验过程可视化（视频流/多视角/录制）；③ 数据分析与决策支持（通量瓶颈、回收率趋势）；④ 预警与应急响应（超温、离心振动 >300 µm、吸空/柱堵等联动急停）；⑤ 成果展示与参观交互（复检机构对外展示）。

# 6. 自动化产能效率

> **口径声明（与 `project/1.html` §7 完全一致）：** 每平台节拍 = Σ 该平台承担各步骤（模块卡 `cycle_time_sec` + 自动上下料 60 s）。**通道数 = 2**，即所有数值均为"双通道、2 样品/循环"节拍（上下料 60 s = 15 s × 2 通道 × 2 上下料）；**单样均摊 = 数值 ÷ 2**。超长步骤（2 h 孵育、2640 s 浓缩、300 s 离心）按国标/卡片取值。

## 6.1 自动化检测效率设计逻辑

- **多模块并行：** SPE（2 台）、浓缩（4 台）、金属浴（64 位批量）并行处理。
- **全流程联动：** 7 工站流水重叠，机械臂衔接工站间流转与 −18 ℃ 冷冻外部节点。
- **节拍匹配（600 s 均衡）：** 按"各平台处理时间尽量接近 600 s"拆分工站，串行瓶颈经并行拉平。

> 以 GB 31658.28—2025 乙酰孕激素（猪/牛/羊/鸡肌肉·脂肪·肝·肾及奶/蛋/尿基质）为工艺样板，全部数值绑定具体样品数与基质：

## 6.4 核心通量与周期保障

- **通量保障：** 稳态通量瓶颈为浓缩工站（WS-06），当前配置浓缩部分 ≈ 675 s/2 样；如需更高通量可升级为 6× `MOD-NS-005`（整平台），浓缩部分降至 ≈ 450 s/2 样。2 h 孵育以 64 位批量并行 + 按日错峰装载消化，不进入单样串行节拍。
- **待客户确认 KPI：** 客户尚未给出"X 天 Y 样 / 年上机 Z 针"硬指标；建议以业务峰值确认后写入合同，并据此决定是否扩容浓缩/离心工站并行数。

## 7.3 项目管理措施

- **进度管理：** 三级管控（项目经理-技术-执行），周例会 + 里程碑评审，设赶工预案。
- **质量管理：** 全流程质控追溯，FAT/SAT 质控节点，原始记录归档，符合 CNAS/CMA 可追溯。
- **沟通管理：** 固定周例会 + 专属沟通群 + 变更书面确认机制。
- **安全管理：** 用电/动火/接地/应急停机规程；权限分级；急停按钮每工位配置；乙腈/甲醇等易燃有机溶剂与强氧化剂分区管理。
- **变更管理：** 书面申请 → 影响评估（进度/成本/技术）→ 双方签字确认后执行。

## 7.4 保障措施

- **资源保障：** 资深工程师 + 原厂部件 + 专用调试设备；甲方配合场地与方法学。
- **技术保障：** 攻坚小组（针对微量加注、离心转速、避光、浓缩方式、SPE 柱型等偏差项）；7×24 远程支持 + 现场响应时限（以售后协议约定）。
- **售后前置：** 售后工程师参与调试阶段，提前熟悉产线。
- **文档保障：** 全流程文档归档、版本受控、可追溯。
